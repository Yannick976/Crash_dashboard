# Crash_dashboard
Dashboard descriptif des accidents de la route en 2024 en France.

## Principaux résultats

- Les accidents sont concentrés dans les zones urbaines.
- Les routes communales représentent la majorité des accidents.
- Les conditions météorologiques normales restent les plus fréquentes.
- Les accidents mortels sont minoritaires mais fortement concentrés sur certaines catégories de routes.
